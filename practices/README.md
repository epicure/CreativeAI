# Practices

창작 실험을 위한 습작 모음입니다. `practices` 폴더 아래의 각 하위 폴더가 하나의 독립적인 실험을 담습니다.

## 폴더 구조 제안
- `practices/<slug>/` : 실험을 나타내는 식별자를 사용합니다. 예: `particle-simulation`
- 각 실험 폴더에는 실행에 필요한 자원(HTML, CSS, JS, 이미지 등)을 한 곳에 모읍니다.
- 필요에 따라 `README.md` 등을 추가해 사용법이나 아이디어를 정리할 수 있습니다.

## 현재 습작 목록
- `particle-simulation/` — HTML5 캔버스를 활용한 바닐라 파티클 플레이그라운드
